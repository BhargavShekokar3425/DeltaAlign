# E08: compiled assignment after selective graph maintenance

Pre-run protocol: fresh seeds 40–44, frozen E07 1K BA attachment 3, descriptor, corrected initial normalization, noise levels, four update budgets and two protocols. Reset trials; no new thresholds. Compare selective maintenance + compiled SciPy, selective maintenance + warm dynamic assignment, full recomputation + SciPy, and keep-old. All share initial graph/cost/mapping controls.

The compiled selective pipeline clones descriptor caches, updates supported features, detects dirty rows/columns, refreshes dense costs and solves the complete assignment with SciPy. It does not clone assignment dual state or run a warm solve. This is an intentional implementation advantage, since these are unnecessary for this method. The paired dynamic pipeline remains E07's kernel. Alternate the order of the two selective pipelines; run full recomputation first. Measure all work from already updated graphs, excluding generation, edge application and validation. Initialization records cache work, custom warm setup and SciPy setup separately; the compiled method does not require warm dual setup.

Require exact feature, dirty-set and cost equality with the full oracle; compiled selective must return the same deterministic SciPy mapping. Warm dynamic must pass its dual certificate and match optimal objective, allowing equal-cost mapping ties. Record NC/S3 and keep-old objective gaps. Five seeds are independent bundles; paired protocol/noise/budget conditions are not extra independent repetitions. Save raw rows, hashes, stage times and median/IQR/ranges. Dense memory and validation-only global checks remain limitations.

The experiment isolates whether warm assignment reuse adds practical benefit beyond selective graph maintenance. Python versus compiled solver differences limit algorithmic conclusions. Do not claim adaptive fallback or stream behavior from reset timings; a persistent fallback to SciPy must restore dual state before later warm solves. Use the results to select a stream reference and assess paper progress, retaining all regimes and objective/truth controls.
