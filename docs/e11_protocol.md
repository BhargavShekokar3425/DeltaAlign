# E11: topology robustness and objective-quality gate

Pre-run protocol: fresh seeds 55–59, 1K vertices, BA attachment 3, ER p=6/(n-1), WS k=6/rewiring 0.1. Record actual edge counts, degree ranges, isolates, connected components and clustering; expected/specified mean degree near six is not exact density matching. New generation code preserves historical graph generation. Initial observation noise uses the same valid mixed-batch construction as prior stages. Truth is generation/evaluation-only.

For each of 30 initial family/noise/seed pairs, save full descriptor alignment and random mapping NC/EC/S3, feature-row uniqueness on both graphs, row-minimum tie frequency and truth row-minimum fraction. Record generation seeds. For every method/stream, run an actual no-update control and require exact unchanged features, normalized features, costs, scale and mappings. Duplicate descriptors/ties or low NC limit correspondence claims; retain difficult families rather than tune or discard them.

Then run 120 ten-step streams (1,200 updates, 4,800 method observations), frozen 0.1%/1% fixed initial per-graph budgets, both noise levels and shared-latent/independent protocols. Compare persistent normalized-cost + selective-feature + SciPy, historical-cost selective + SciPy, full + SciPy and keep-initial. Reuse unchanged E10 pipeline kernels. No warm fallback, parameter tuning or approximate search.

Every step requires bitwise feature/dirty-set/normalized-feature/cost equality and identical SciPy mappings. Shared observation masks remain fixed; independent drift and quality are logged. Count real method-specific initialization plus cumulative stages/updates. Full method runs first; selective order alternates. Generation/batch application, diagnostics and validation are excluded from graph-to-assignment timings. No-update diagnostics are separately recorded and not treated as ten-stream updates or free initialization work.

Aggregate correlated steps within each seed/stream, then report five paired seed distributions per family/noise/protocol/budget. Families/conditions share seed branches; do not pool them as independent samples. Show feature, cost, update-only and setup-inclusive gains, support/dirty expansion and NC/S3 separately. Component improvement counts positively even if total performance regresses. Array bytes are not peak RSS; no large-size/long-stream/parallel or verified novelty claim follows from this gate.
